# DSC 650 — Big Data Architecture Final Project

> **End-to-end data engineering and machine learning pipeline built across the Hadoop ecosystem.**

## Project Overview

This project delivers a complete big data pipeline that integrates **Apache NiFi, HDFS, Hive, Spark MLlib, HBase, and YARN** into a single end-to-end architecture. It demonstrates how distributed data platforms can ingest raw data, persist it at scale, expose it through SQL, apply machine learning, and store model results for downstream access and verification.

### End-to-End Data Flow

**Source Data → Apache NiFi → HDFS → Apache Hive → Apache Spark MLlib → Apache HBase**

Spark workloads are submitted through **YARN** for distributed resource management.

## Engineering Capabilities Demonstrated

- **Apache NiFi — Data Ingestion & Orchestration**  
  Ingests the source dataset, manages the flow of data, and writes records into HDFS.

- **Hadoop/HDFS — Distributed Storage**  
  Provides the persistent distributed storage layer used by the downstream analytics pipeline.

- **Apache Hive — SQL Data Access**  
  Structures the data as a managed Hive table and enables SQL-based querying, validation, and aggregation.

- **Apache Spark MLlib — Distributed Machine Learning**  
  Reads data from Hive, performs distributed processing, trains and evaluates a machine learning model, and generates model-performance metrics.

- **YARN — Cluster Resource Management**  
  Executes and manages the Spark workload across the Hadoop environment.

- **Apache HBase — NoSQL Metrics Persistence**  
  Stores machine learning metrics generated by Spark and supports record-level retrieval and scan-based verification.
