## Portfolio quality

- [ ] README explains the project in less than 3 minutes of reading
- [ ] Architecture diagram is readable
- [ ] File names are descriptive
- [ ] Repository is organized by technology/function
- [ ] Code includes brief comments where useful
- [ ] Screenshots are cropped and readable
- [ ] The repository does not look like a collection of weekly homework folders
- [ ] GitHub links and images render correctly

## Final test

Ask yourself:

> Could a technical interviewer understand what I built, how the pieces connect, and what I personally implemented without access to my Google Cloud environment?

If yes, the portfolio is ready.
